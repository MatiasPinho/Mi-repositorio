# Prompt para Claude Design

Quiero que rediseñes el sistema visual de este proyecto. Antes de tocar código, leé `DESIGN-BRIEF.md`, `design/README.md`, `skills-src/study-design/SKILL.md`, el rubric del reviewer y los tres casos de `docs/design-samples/`.

No quiero pequeños retoques: proponé una dirección visual coherente y aplicala al design system.

## Objetivo
Que los apuntes se sientan como un **libro universitario técnico contemporáneo**, extremadamente cómodo para estudiar durante 1–2 horas. Debe ser minimalista, tranquilo y académico, sin verse viejo ni parecer una interfaz SaaS.

## Tenés libertad para cambiar
- familias tipográficas y pairing;
- escala tipográfica;
- jerarquía de títulos;
- measure, line-height y ritmo vertical;
- composición de capítulo/apertura;
- tratamiento de figuras y captions;
- tablas;
- callouts semánticos;
- código/pseudocódigo;
- navegación de guías largas;
- versión móvil e impresión/PDF.

## No hagas
- dashboard/cards por todos lados;
- estética SaaS;
- gradients, glassmorphism, chips o badges decorativos;
- fake paper texture, grain, líneas de cuaderno o vintage cosplay;
- color ornamental;
- tipografía deliberadamente anticuada sólo para que parezca un libro;
- hero titles gigantes;
- bloques de código oscuros que dominen la página;
- cambios en pipelines académicos o procesamiento de fuentes.

## Criterio principal
El estudiante debería poder leer esto una hora y sentir que está usando un gran manual universitario, no una página web estilizada.

Probá la propuesta mentalmente contra los tres stress cases: teoría, Arquitectura con diagramas y Sistemas Operativos con tablas/callouts. No optimices sólo para uno.

Al terminar, explicá brevemente las decisiones de tipografía, jerarquía, spacing, color, figures/tables y por qué mejoran la lectura prolongada.
