# Design review — V3.4

Direction remains **academic paper reader**. V3.4 is a refinement, not a redesign.

## Changes under review
- summaries/reviews have no persistent TOC; long guides may keep a quiet editorial index;
- prose measure is separate from paper width so technical figures/tables can breathe;
- figure captions are auto-numbered like a textbook;
- tables look like manual/reference tables rather than web widgets;
- generic chrome is reduced to the artifact label and a hairline;
- body rhythm is slightly tighter while remaining comfortably above WCAG's 1.5 spacing reference point.

## Reject if
- wider paper causes prose lines to become wider;
- figures feel detached from their explanations;
- the guide TOC competes with the paper;
- tables resemble application UI;
- the new spacing feels cramped during sustained reading.
