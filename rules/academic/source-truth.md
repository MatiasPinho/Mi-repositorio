# Academic source truth

## Source hierarchy
1. Official regulations, syllabus, assessment instructions and formal chair/professor announcements.
2. Official written teaching material: PDFs, slides, guides, exercises and problem sets.
3. Official class/video transcripts: authoritative for what was taught, examples and teaching emphasis; conversational claims still need contextual interpretation.
4. Student notes.
5. External knowledge only as clearly separated pedagogical support.

Course-specific official rules override generic university conventions.

## Evidence is internal by default
Store pages, timestamps, fingerprints, exact wording and conflicts so claims can be audited. Do **not** automatically surface that machinery in student-facing prose.

## No silent repair
Do not silently correct, reconcile or replace a course source using general knowledge. If sources conflict, preserve the conflict internally. A student-facing artifact may present the practical interpretation succinctly, but must not hide uncertainty that changes what the student should answer or do.
