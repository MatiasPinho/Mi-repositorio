# Guide artifact

A guide may be exhaustive, but must still teach progressively.

It can include deeper worked examples, alternative formulations, relevant source conflicts, edge cases and extended explanations. Documentary evidence belongs in unobtrusive notes or dedicated conflict/source sections, not inside every paragraph.

Use relevant source figures and diagrams when they explain structure/process/relationships better than prose. A figure must be interpreted for the learner; never dump screenshots without telling the student what to notice.

Write semantic Markdown compatible with the visual system and render to HTML for reading. Exhaustiveness never licenses unreadable prose or decorative clutter.
