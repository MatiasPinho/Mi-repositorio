# Component grammar

Allowed learning components:
- ordinary prose in the gutter/body row primitive;
- numbered section headings;
- lists;
- table;
- figure plate + numbered caption;
- semantic rail: definition/concept, example, warning/exam, error, connection;
- visible recall/retrieval block.

Do not add a new component merely because a new concept appears. Add one only when a genuinely different reading behavior is required.

Semantic rails use a textual label in the gutter and a thin rule beside the body. Most remain transparent. Warning/error can use a slightly stronger treatment when urgency is real.

Recall prompts are visible by default so the learner notices the retrieval opportunity without opening a disclosure. Keep them sparse: visibility is useful only when the page is not saturated with questions.
