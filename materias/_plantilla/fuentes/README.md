# Fuentes

Acá van los materiales originales de la materia. La estructura recomendada es:

- `oficiales/`: programa, pautas de cursada, cronogramas, PDFs, diapositivas, guías, parciales anteriores y otros materiales escritos oficiales.
- `transcripciones/`: transcripciones de clases o videos en `.txt`, `.md`, `.srt` o `.vtt`.

El sistema escanea recursivamente `fuentes/`, así que también podés crear subcarpetas por unidad si te resulta útil.

No pongas resúmenes generados por IA acá: esta carpeta debe conservar las fuentes originales.
