# Typography rules

- Body copy is the product. Optimize for sustained reading, not dashboard density.
- Current canonical roles: Source Serif 4 for body/display, IBM Plex Sans for utility labels/captions/TOC, IBM Plex Mono for code.
- Webfonts are progressive enhancement only. Keep complete system fallbacks so the HTML remains usable offline.
- Default body target: ~19px desktop with line-height ~1.72; compact screens may reduce slightly through the responsive clamp.
- Keep prose around 42rem / roughly 60–75 characters. Technical figures, tables and code may use the wider 52rem measure.
- Headings describe the concept being learned. They are not decorative labels.
- Use the utility face for gutter labels, section numbers, captions, running lines and navigation.
- Use bold selectively. Underline is for links, not emphasis.
- Never justify body text.

External references remain guidance rather than immutable values:
- GOV.UK Design System type scale: https://design-system.service.gov.uk/styles/type-scale/
- Carbon typography: https://carbondesignsystem.com/elements/typography/overview/
- WCAG 2.2 visual presentation/text spacing: https://www.w3.org/TR/WCAG22/
