# Study design review rubric

Score 0–5:
- hierarchy
- sustained readability
- typography
- spacing rhythm
- color/signaling discipline
- figure integration
- table/code treatment
- responsive behavior
- print quality
- accessibility
- consistency across subjects

Reject when any major dimension is below 4 or when a hard failure exists.

## Hard failures
- horizontal prose scrolling;
- body contrast below accessible threshold;
- unreadable figure labels;
- decorative card soup;
- semantic meaning conveyed only by color;
- fake paper/vintage texture that reduces clarity;
- dark/oversaturated component that dominates a calm reading page without pedagogical need;
- sidebar/navigation on a short summary that steals reading width;
- technical table/figure forced into the same narrow measure as prose when that damages comprehension.
