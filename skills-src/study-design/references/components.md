# Component grammar

Allowed learning components:
- ordinary prose;
- headings;
- lists;
- table;
- figure + caption;
- semantic rail: definition/concept, example, warning/exam, error, connection;
- collapsed recall block.

Do not add a new component merely because a new concept appears. Add a component only when a genuinely different reading behavior is required.

Semantic rails are the visual signature. Most of their surface remains transparent; the colored rail and small label communicate role. Warning/error can use a slightly stronger wash when urgency is real.

Recall is interactive and visually distinct because its behavior is different: the learner should attempt retrieval before opening it.
