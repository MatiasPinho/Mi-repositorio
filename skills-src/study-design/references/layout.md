# Layout

Use one dominant reading column. Navigation is optional and artifact-dependent, never a competing panel.

The document must work as a single-column article on narrow screens.

Spacing encodes relationships:
- smaller gaps inside one conceptual group;
- larger gaps between conceptual sections;
- clear chapter/section transitions;
- figures and their interpretation stay close.

Avoid nested cards. A student should be able to trace the page vertically without jumping between containers.

Prose measure should remain narrower than the maximum sheet width. Figures, tables, equations, and code may use additional width when comprehension benefits.

Tables may scroll horizontally on small screens; prose must not.
