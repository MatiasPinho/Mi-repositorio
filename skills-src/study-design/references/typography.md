# Typography rules

- Body copy is the product. Optimize for 20–40 minute reading sessions, not information density.
- Use a restrained, contemporary stack suitable for sustained reading. Avoid both generic SaaS typography and overtly old-fashioned book typography.
- Keep the reading measure around 60–75 characters; never intentionally exceed 80 for prose.
- Headings describe the concept being learned. They are not decorative labels.
- Use a small utility type role for captions, semantic labels and optional TOC.
- Use bold selectively. Underline is for links, not emphasis.
- Never justify body text.
- Headings should feel editorial but restrained: no oversized hero typography.

External design references:
- GOV.UK Design System type scale: https://design-system.service.gov.uk/styles/type-scale/
- Carbon typography: https://carbondesignsystem.com/elements/typography/overview/
- WCAG 2.2 visual presentation/text spacing: https://www.w3.org/TR/WCAG22/

Typography is intentionally open for redesign. Do not assume Georgia/Cambria/Constantia/Sitka/Aptos is the final answer; evaluate the page as a whole.
